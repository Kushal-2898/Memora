1. Zero-Bloat Data Model

In Ponytail Ultra mode, we do NOT create a separate Habit tracking table. We simply reuse your existing Reminder and EventType models.

// In EventType.kt:
enum class EventType {
  EXPIRATION, DUE_DATE, WARRANTY_END,
  DAILY_REGIMEN, OTHER
}

2. Daily Recurrence Alarms

Your ReminderAlarmReceiver already has daily rescheduling logic (today.plusDays(1)) for uncompleted items. When marked "Applied", it simply advances the alarm to tomorrow morning at the exact set time (e.g. 8:30 AM).

// When user taps "Mark Applied":
reminder.copy(
  reminderStartDate = today.plusDays(1),
  reminderTime = LocalTime.of(8, 30)
)

3. Notification Action Button

The push notification gives a direct Mark Applied action. Tapping it updates the database and dismisses the alert without opening the app.

.addAction(0, "Mark Applied", pendingIntent)
.addAction(0, "Snooze 15m", snoozeIntent)

4. PAO (Period After Opening) Countdown

When scanning a tube or bottle (e.g. 6M / 12M jar symbol), Memora records firstOpenedDate = today and automatically calculates expiration as today + 6 months.

// Computed from first usage:
val expiryDate = openedDate.plusMonths(6)
